About EcoBuild

EcoBuild: AI-Based Building Energy Efficiency Analysis System

Project Purpose

EcoBuild is an academic decision-support web application developed to demonstrate how machine learning can assist early-stage building energy analysis. The system accepts eight physical building parameters and predicts Heating Load and Cooling Load values using a trained Gradient Boosting model. A What-If Analysis feature enables users to create named scenarios and compare how parameter modifications affect predicted energy loads.

SDG 7 Connection

EcoBuild directly supports UN Sustainable Development Goal 7: Affordable and Clean Energy. Buildings are responsible for a large share of global energy consumption. By enabling accessible, early-stage energy estimation, EcoBuild encourages energy-conscious design decisions that can reduce long-term operational energy demand.

ML-Based Prediction

Predictions are generated by two independently trained GradientBoostingRegressor models — one for Heating Load and one for Cooling Load. Both models were trained on the UCI Energy Efficiency dataset (ENB2012) using a strict train/test split (80%/20%, random_state=42) and 5-fold cross-validation for model selection. The test set was evaluated exactly once after model selection.

  • Heating Load — Test R²: 0.9984, MAE: 0.28, RMSE: 0.41
  • Cooling Load — Test R²: 0.9889, MAE: 0.69, RMSE: 1.02

What-If Analysis Concept

After performing a base analysis, users can create named What-If scenarios by modifying one or more building parameters. The system predicts new loads for each scenario and allows side-by-side comparison, supporting informed design iteration without requiring specialist energy simulation software.

UCI Energy Efficiency Dataset

The dataset used to train EcoBuild's models is the publicly available UCI Energy Efficiency dataset (ENB2012), compiled by Athanasios Tsanas and Angeliki Xifara. It contains 768 simulated building configurations generated using the Ecotect simulation tool, each described by eight input features and two output targets (Heating Load, Cooling Load).

Project Limitations

  • Predictions are based solely on the eight UCI ENB2012 features and do not account for climate zone, occupancy, HVAC system type, or material properties beyond those captured in the dataset.
  • The training dataset contains 768 samples from a controlled simulation study; real-world buildings may fall outside the training distribution.
  • EcoBuild does not perform certified energy compliance calculations.
  • This prototype is intended for academic and educational use only.
Disclaimer: EcoBuild is an academic decision-support prototype. Predictions are estimates based on benchmark data and are not professional engineering certification or guaranteed real-world energy consumption.
